# 📘 راهنمای جامع فیلدها و استانداردهای تحویل بسته تمرینات تخصصی رالی
> این سند راهنمای رسمی برای تهیه‌کنندگان محتوا، بازبینان تخصصی و مدیران محتوای پلتفرم رالی است.

---

## ۱. تفکیک نقش‌ها و مسئولیت‌ها

| نقش | مسئولیت در پایپ‌لاین | خروجی مورد انتظار |
| :--- | :--- | :--- |
| **تهیه‌کننده محتوا (Creator)** | تامین محتوای متنی، فایلهای رسانه و مستندات اصالت اثر | فایل `content.json`، تصاویر و ویدیوهای خام باکیفیت |
| **بازبین تخصصی ورزشی (Expert Reviewer)** | بررسی صحت حرکتی، تناسب با سطح، وضوح آموزش و نکات ایمنی | ثبت فرم چک‌لیست بازبینی و تایید یا اعلام اصلاحات |
| **مدیر محتوا (Content Manager)** | بررسی حقوق لایسنس، وضعیت رسانه‌ها و انتشار نهایی در پلتفرم | تغییر وضعیت به PUBLISHED و نظارت بر دسترسی |
| **نرم‌افزار رالی (Software)** | اجرای کنترل‌های دسترسی، انقضا، همروندی، رمزنگاری و استریم امن | محافظت از دارایی‌ها و جریان تعاملی کاربر |

> [!IMPORTANT]
> نام مربی، صلاحیت حرفه‌ای، تایید حرکت یا اجازه استفاده هرگز توسط داده‌های فرضی هوش مصنوعی یا سیستم نرم‌افزاری تولید نمی‌شود و باید منحصراً توسط افراد دارای صلاحیت حقیقی ثبت شود.

## ۲. مشخصات فیلدهای متنی (`content`)

| فیلد | نوع داده | محدودیت / اعتبارسنجی | شرح و کاربرد |
| :--- | :---: | :---: | :--- |
| `drill_slug` | رشته | `^[a-z0-9]+(?:-[a-z0-9]+)*$` | شناسه یکتای URL تمرین (مثال: `bandeja-foundation-basics`). |
| `title` | رشته | ۳ تا ۲۵۵ کاراکتر | عنوان فارسی جذاب و استاندارد تمرین. |
| `sport` | کلید واژه | `PADEL` یا `TENNIS` | رشته ورزشی تمرین. |
| `category` | کلید واژه | `TECHNIQUE`, `TACTICS`, `PHYSICAL_FITNESS`, `MENTAL_SKILLS` | دسته‌بندی موضوعی تمرین. |
| `level` | کلید واژه | `BEGINNER`, `INTERMEDIATE`, `ADVANCED`, `PRO` | سطح مهارتی مخاطب. |
| `participant_type` | کلید واژه | `SOLO`, `PAIR`, `GROUP` | نحوه اجرای تمرین (انفرادی، دونفره، گروهی). |
| `summary` | متن | ۱۰ تا ۱۰۰۰ کاراکتر | خلاصه موجز برای کارت تمرین در صفحه فهرست. |
| `objective` | متن | ۱۰ تا ۱۰۰۰ کاراکتر | هدف آموزشی دقیق و تاثیر تمرین بر بازی بازیکن. |
| `duration_minutes` | عدد صحیح | بین ۱ تا ۱۸۰ دقیقه | **زمان کل اجرای تمرین در کورت ورزشی** (کاملاً مجزا از طول ویدیو!). |
| `equipment_required` | آرایه متنی | حداقل ۱ مورد | وسایل مورد نیاز (راکت، توپ، مخروط، کش و...). |
| `steps` | آرایه آبجکت | حداقل ۱ مرحله | مراحل گام‌به‌گام شامل `step_number`, `title`, `instruction`, `reps_or_time`, `key_focus`. |
| `common_mistakes` | آرایه آبجکت | اختیاری | خطاهای رایج بازیکنان به همراه راهکار تصحیح (`mistake`, `correction`). |
| `safety_precautions` | آرایه متنی | حداقل ۱ مورد | نکات ایمنی و احتیاطی جهت جلوگیری از آسیب مفاصل یا برخورد با شیشه/تور. |

## ۳. مشخصات دارایی‌های رسانه‌ای (`media_assets`)

| فیلد | نوع داده | مقادیر مجاز | شرح فنی |
| :--- | :---: | :---: | :--- |
| `media_type` | کلید واژه | `IMAGE`, `VIDEO`, `SUBTITLE`, `DIAGRAM` | نوع رسانه. |
| `video_duration_seconds` | عدد صحیح | برحسب ثانیه (مثال: ۱۱۰) | **طول ویدیوی آموزشی به ثانیه** (مجزا از زمان تمرین در کورت). |
| `aspect_ratio` | رشته | `16:9` یا `9:16` | نسبت تصویر پیشنهادی (دسکتاپ یا موبایل). |
| `provenance` | کلید واژه | `REAL_RECORDING`, `AI_GENERATED`, `HYBRID`, `UNSPECIFIED` | منشأ تولید اثر. (ثبت `AI_GENERATED` به معنی تایید اتوماتیک آن نیست). |
| `usage_rights_status` | کلید واژه | `OWNED`, `LICENSED`, `PUBLIC_DOMAIN`, `UNAUTHORIZED` | وضعیت حقوقی انتشار. فایل با وضعیت `UNAUTHORIZED` مسدود است. |
| `license_details` | متن | تا ۵۰۰ کاراکتر | مرجع حقوقی، شماره قرارداد یا نام دارنده پروانه اثر. |

## ۴. چک‌لیست فرم بازبینی تخصصی (`sample_review_checklist`)

بازبین تخصصی پیش از تایید نسخه موظف است این ۵ شاخص را بررسی و در فرم قید نماید:
1. **تناسب ورزشی (`suitability_approved`):** آیا آموزش برای ورزش، سطح و هدف تعیین‌شده مناسب و استاندارد است؟
2. **وضوح اجرای حرکت (`movement_clarity_approved`):** آیا ضربه، جاگیری و زوایای بدن در ویدیو/متن به وضوح نمایش داده شده است؟
3. **هماهنگی متن و رسانه (`media_sync_approved`):** آیا توضیحات گام‌ها با اجرای ویدیویی و زیرنویس همخوانی دارد؟
4. **اشکالات و ابهامات آموزشی (`pedagogical_notes`):** ثبت هرگونه نقص آموزشی که باید تصحیح شود.
5. **نکات ایمنی و بهداشتی (`safety_notes`):** درج خطرات احتمالی اجرای ناصحیح حرکت برای بازیکن.
