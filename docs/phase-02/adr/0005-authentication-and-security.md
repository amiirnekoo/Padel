# ADR-005: الگوی احراز هویت پیامکی (SMS OTP) و کنترل دسترسی مبتنی بر نقش (RBAC)

**وضعیت:** پذیرفته‌شده (Accepted)
**تاریخ:** 2026-09-21
**تصمیم‌گیرندگان:** تیم مهندسی و مالک محصول

## زمینه و مسئله (Context)

در حوزه رزرو زمین‌های ورزشی، کاربران تمایلی به حفظ کلمه‌های عبور پیچیده ندارند و ثبت‌نام سریع با شماره موبایل اصلی‌ترین عامل کاهش اصطکاک ورود است. هم‌زمان، سامانه دارای ۴ نقش کاربری متمایز با سطوح دسترسی کاملاً تفکیک‌شده است:
1. `Platform Admin`: دسترسی کامل به تنظیمات مالی، کارمزدها، لاگ‌های ممیزی و صف خطاهای استرداد.
2. `Club Owner`: دسترسی به گزارش‌های تسویه، شماره شبا، و تنظیمات باشگاه.
3. `Club Operator`: دسترسی محدود به تقویم، مسدودسازی دستی سانس (`BLOCKED`)، لغو اضطراری و ثبت No-Show.
4. `Player`: رزرو آنلاین، مشاهده تقویم، پرداخت و لغو سانس‌های متعلق به خود.

## تصمیم (Decision)

1. **جریان احراز هویت دو مرحله‌ای (SMS OTP):**
   - **ارسال کد:** تولید کد اعتبارسنجی ۵ رقمی تصادفی با انقضای ۲ دقیقه‌ای (`expires_at = now + 120s`).
   - **محدودیت نرخ (Rate Limiting):** حداکثر ۳ درخواست کد پیامکی در هر ۱۰ دقیقه برای یک شماره موبایل مشخص جهت جلوگیری از سوءاستفاده پیامکی (SMS Flooding).
   - **اعتبارسنجی و صدور توکن:** با ارسال کد صحیح، سیستم توکن دسترسی امضاشده (`Access Token` با الگوریتم HMAC-SHA256 و اعتبار ۱۵ دقیقه) و توکن تازه‌سازی (`Refresh Token` با اعتبار ۳۰ روز در کوکی HttpOnly امن) صادر می‌نماید.

2. **کنترل دسترسی مبتنی بر نقش (Role-Based Access Control - RBAC):**
   - پیاده‌سازی گارد دسترسی در سطح FastAPI Dependencies:
     ```python
     def require_role(allowed_roles: list[RoleEnum]):
         async def dependency(current_user: User = Depends(get_current_active_user)):
             if current_user.role not in allowed_roles:
                 raise HTTPException(status_code=403, detail="دسترسی غیرمجاز")
             return current_user
         return dependency
     ```
   - متصدی باجه پذیرش (`Club Operator`) صرفاً به سانس‌های متعلق به باشگاه خود دسترسی ویرایش دارد (`club_id check`).

## پیامدها (Consequences)

### پیامدهای مثبت:
- تجربه کاربری سریع و منطبق با عادات رفتاری کاربران در ایران.
- امنیت بالای توکن‌ها با ذخیره Refresh Token در کوکی امن، محافظت در برابر حملات XSS و CSRF.
- جداسازی قطعی اختیارات عملیاتی و مالی در سطح باجه، مدیر باشگاه و ادمین پلتفرم.
